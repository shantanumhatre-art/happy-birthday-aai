# Happy Birthday Aai ❤️

Open the folder in VS Code and run index.html with Live Server.

## Add music
Put an MP3 song inside `assets/music/` and name it exactly `birthday.mp3`.
When Aai clicks **Open My Surprise 🎁**, the song starts automatically.

## Add photos
Put photos in `assets/photos/` using the names `photo1.jpg` through `photo6.jpg`.
